Waarom noem je de eerste HTML-pagina meestal index.html?

Omdat webbrowsers nog altijd zoeken naar de verkortingen van een home page wat vroeger Index was dus ze worden zo nogsteeds genoemt

Welke HTML-standaard gebruiken webontwikkelaars tegenwoordig en waarom wordt deze een "Living Standard" genoemd?

html:5 is de HTML-standdaard en wordt ook wel een living standard genoemd omdat er altijd nog updates aan komen zoals html:6

Waarom spreken webontwikkelaars tegenwoordig meestal niet meer over één specifieke CSS-versie?

Ze spreken over meerderere bronnen omdat er snapshots voor een nieuwe versie elke 2 jaar uit zou moeten komen en dat ze in die periode ook stabaliseren. Het verandert zo snel dat ze dus nooit altijd over een specifieke soort CSS-versie.

Waarom ziet een website er soms net iets anders uit in verschillende browsers, zoals Chrome, Firefox of Safari?

Omdat alle browsers een andere rendering motor hebben dus de styling van de website wordt aangepast om in de browser te passen dat de rendering motor kan renderen.
